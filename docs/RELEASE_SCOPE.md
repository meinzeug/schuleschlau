Die technische Durchführung und Nachtests verantwortet die Entwicklung; die
fachliche Prüfung benötigt eine dafür geeignete fachkundige Person. Der
Betreiber entscheidet Umfang, Betrieb und Support. Datenschutzbewertung und
gegebenenfalls unabhängige Sicherheitsprüfung gehören an entsprechend
qualifizierte Stellen. Rollen sind hier bewusst keine erfundenen Namen oder
erteilten Unterschriften. Fehlende Nachweise bedeuten keine Freigabe.

Eine Freigabe für eine spätere Stufe verlangt eine eigene datierte Entscheidung
zu Version, Teilnehmern, Funktionen, Einschränkungen und Verantwortlichen.
Bestehende Freigaben für diese Installation bleiben davon unberührt; diese
Matrix aktiviert weder Anbieter noch Geräte, Push oder Verkauf.
